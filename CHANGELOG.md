# Changelog

What a teacher or a student notices in each desktop version. `tools/release-github.ps1` takes the
section of a version as the notes of its GitHub release, and refuses a version without one.

## 0.2.0

- The Studio has a single visual editor: the Markdown source view is gone, and a file that cannot
  be read is refused with the line at fault.
- The author picks which interface languages students may use for a paper.
- In practice mode, handing in opens the correction straight away, with save and share first.
- The student correction has no print button any more, and theme rates sit under their names on
  phones.
- The validator speaks French as well as English and links each warning to the writing guide.
- With copies loaded in Correct, the editor shows the class results of every question.

## 0.1.1

- The Studio and the player carry the MCQ Advanced icon: programs, windows, shortcuts and menus.

## 0.1.0

- First desktop builds of the Studio and the player, for Windows and Linux.
